# CampusPulse Admin Dashboard

Responsive frontend recreation of the supplied CampusPulse admin dashboard references.

## Run locally

```bash
npm install
npm run dev
```

The app runs on port 3000. Use `npm run build` to create the static `dist/` output.

## Included screens

The single-page app includes the dashboard, student records, faculty management, timetable management, assignment management, scholarship tracker, fees and submissions, grievance management, student support, e-library, examination management, notices and announcements, course information, agentic workflow, and admin settings/security routes.

## Frontend behavior

Navigation is route-aware, with a responsive mobile drawer, collapsible desktop sidebar, theme toggle, global search modal, creation modals, filters, table search, status badges, pagination affordances, toast feedback, student profile modal, and simulated agentic workflow execution with approval gating.
