# Authentication notes (superseded)

This file describes an earlier Supabase Auth implementation and is **not** the current browser sign-in contract. CampusPulse now uses Clerk for sign-in and a Clerk-issued JWT for Supabase requests.

For current setup requirements, profile mapping, security boundaries, and known limitations, read [Clerk and Supabase authentication](clerk-supabase-auth.md). For the code and data flow, read [the architecture guide](../architecture.md).
